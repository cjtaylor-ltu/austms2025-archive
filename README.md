# AustMS 2025 conference website archive

This repository contains a reconstructed archival version of the website for the 69th Annual Meeting of the Australian Mathematical Society (AustMS), held at La Trobe University in December 2025.

The site has been reconstructed from the original conference website as a static Jekyll site. The aim is to preserve the content and appearance of the original site while removing its dependency on the original website platform and services that are no longer available. Some implementation details have been replaced or simplified during reconstruction. The substantive content of the original website has generally been preserved rather than editorially revised.

## Repository structure

- `_data/` — structured data used to generate parts of the site
- `_includes/` — reusable Jekyll includes
- `_layouts/` — Jekyll page layouts
- `assets/files/` — conference documents and downloadable files
- `assets/images/` — general site images
- `assets/photos/` — conference photo galleries
- `pages/` — reconstructed site pages

## Conference photographs

The photographs in `assets/photos/` are web-optimised derivatives of the photographs used on the original conference website.

The archival source photographs are not included in this repository.
